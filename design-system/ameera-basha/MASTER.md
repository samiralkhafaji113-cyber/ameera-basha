# Design System – Ameera Basha Complex (MASTER v2)

Integrated workflow: **official logo → brand analysis (`docs/brand-guidelines.md`) → ui-ux-pro-max database → design-system tokens → components (Tailwind) → design/UX review → brand consistency check.**

Source of truth: `design/tokens.json` → `src/styles/tokens.css` (generated by the `design-system` skill's `generate-tokens.cjs`) → Tailwind theme in `src/app/globals.css`.

## 2. Decisions

| Decision | Pick | DB IDs | Why |
|---|---|---|---|
| Style (primary) | **Minimalism & Swiss Style** – recommended by the DB for fashion (#133 «Wardrobe & Outfit Planner») | Style **#1** | Thin geometric monochrome logo → hairlines, grid, generous white space |
| Style (surface/depth) | **Soft UI Evolution** – #133's secondary style | Style **#19** | Soft multi-layer shadow, 8–16px radius, ≥4.5:1 contrast, 200–300 ms motion |
| Style (family/a11y) | **Accessible & Ethical** – #137's secondary style | Style **#8** | Family audience, 44px targets, visible focus, large text |
| Warmth | Nature Distilled (sand surfaces only) | Style **#61** | Keeps it retail-friendly, not a cold "luxury house" |
| Rejected | Exaggerated Minimalism (#47: «avoid: e-commerce catalogs»), Editorial Grid (#66: «avoid e-commerce catalogs»), Glassmorphism/Liquid Glass (DB default for luxury: heavy on slow phones), Vibrant & Block (playful) | | |
| Landing pattern | Feature-Rich Showcase (+ conversion CTAs) | Landing **#31** | Hero → category cards → featured → benefits → CTA |
| Palette | **E-commerce Luxury** = **Luxury/Premium Brand** (identical values) with the primary replaced by the **measured logo ink #050505** | Palette **#4** (#33) | Warm stone neutrals + gold accent mirror the storefront; ink from the official logo |
| Typography | Headings **Noto Kufi Arabic**, body **Noto Sans Arabic** | google-fonts DB (Arabic subset); body from pairing **#26** | Kufi is a geometric mono-line Arabic → echoes the logo's thin Arabic lettering; replaces the earlier Naskh heading |
| UX rules applied | #90 no-results with suggestions; #115 chips wrap instead of horizontal scroll; #64/#2 mobile-first & sticky nav padding | | |

## 3. Tokens (brand-derived → final)

- **Brand-derived (measured from the official logo):** ink `#050505`, paper `#FFFFFF`.
- **Primary** `#050505` · **Secondary** `#44403C` · **Accent** `#A16207` (text variant `#854D0E`) · **Background** `#FAFAF9` · **Surface** `#FFFFFF` · warm surfaces `#FBF8F3 / #F5EEE4 / #EADFCF` · **Text** `#0C0A09` · **Muted** `#57534E` · **Border** `#D6D3D1` · **Success** `#15803D` · **Warning** `#B45309` · **Error** `#B91C1C` · WhatsApp `#15803D`.
- **Spacing:** 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64. **Radius:** 8 / 10 / 16 / pill. **Shadows:** sm / md / lg. **Motion:** 150 / 220 / 320 ms, reduced-motion respected.
- **Type scale:** H1 clamp(1.75rem…3rem)/1.4 · H2 clamp(1.5rem…2.25rem)/1.45 · H3 1.125rem · Body 1rem/1.75 · Caption 0.75–0.875rem · Button 0.9375rem/600.
- Deviations from the DB: error `#DC2626` → `#B91C1C`, muted `#475569` → `#57534E` (contrast on tinted/warm backgrounds).

## 5. Layout rules

Mobile-first; container 76rem, gutter 16/24/32px; breakpoints 640 / 768 / 1024 / 1280. Touch targets ≥ 44px. Logical properties (`ms/me/ps/pe/start/end`) for future LTR. Header height 84px (`--header-h`).
